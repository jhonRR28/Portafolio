# 🚀 Developer Portfolio | Ingeniero de Sistemas

¡Bienvenido a mi portafolio profesional! Este proyecto es una Single Page Application (SPA) responsiva diseñada y desarrollada desde cero para mostrar mi stack tecnológico, habilidades técnicas y los proyectos más destacados en los que he trabajado.

La arquitectura del sitio prioriza el rendimiento, animaciones fluidas y una experiencia de usuario moderna y minimalista, ideal para perfiles de ingeniería de software.

---

## 🛠️ Stack Tecnológico

El proyecto fue construido utilizando un entorno moderno de desarrollo web enfocado en la velocidad de compilación y optimización de estilos:

*   **Core:** React (JavaScript) + Vite ⚡
*   **Estilos:** Tailwind CSS v4 🎨 (Implementando selectores avanzados y gradientes nativos).
*   **Animaciones:** Motion (Framer Motion) 🎬 (Transiciones sutiles y efectos interactivos al hacer scroll).
*   **Iconografía:** React Icons 📦

---

## 🖥️ Características Clave

*   **Diseño Totalmente Responsivo:** Optimizado meticulosamente para dispositivos móviles, tabletas y computadoras de escritorio mediante breakpoints de Tailwind.
*   **Estilo Moderno:** Interfaz oscura (Dark Mode nativo) con un fondo de gradiente radial centrado para mitigar la fatiga visual.
*   **Animaciones Fluidas:** Interacciones dinámicas en la barra de navegación y efectos *fade-in* en las tarjetas de proyectos sin comprometer el rendimiento de carga.

---

## 📁 Estructura del Proyecto

La arquitectura de archivos mantiene un orden modular basado en componentes limpios y reutilizables:

```text
src/
├── assets/          # Imágenes, capturas de proyectos y recursos estáticos
├── components/      # Bloques de construcción independientes de la interfaz
│   ├── Navbar.jsx   # Barra de navegación interactiva
│   ├── Hero.jsx     # Sección de presentación principal y CTA
│   ├── Tech.jsx     # Panel interactivo de habilidades y herramientas
│   ├── Projects.jsx # Cuadrícula de tarjetas de proyectos técnicos
│   └── Contact.jsx  # Sección y enlaces de redes profesionales
├── App.jsx          # Componente principal que orquesta el lienzo y el fondo
└── main.jsx         # Punto de entrada de la aplicación en el DOM
```

## ⚡ Instalación y Configuración Local

Si deseas clonar este portafolio y ejecutarlo en tu entorno local, asegúrate de tener instalado **Node.js 24 (LTS)** o superior. Sigue estos pasos en tu terminal:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com
   cd TU_REPOSITORIO
   ```

2. **Instalar dependencias de forma limpia:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo local:**
   ```bash
   npm run dev
   ```
   *El proyecto estará disponible para su previsualización en `http://localhost:5173`.*

4. **Compilar para producción (Producción optimizada):**
   ```bash
   npm run build
   ```
